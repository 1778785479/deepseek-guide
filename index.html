HOW TO USE

怎么用 DeepSeek？四种方式

网页免费聊、App 随身用、API 接程序、开源权重自己部署 —— 总有一种适合你

01

网页版 Chat

chat.deepseek.com · 免费

  1. 浏览器打开 chat.deepseek.com，手机号或邮箱注册登录
  2. 默认使用 DeepSeek-V4 系列，免费无限对话
  3. 需要深度推理时点击「深度思考」切换 R1 推理模式
  4. 点击「联网搜索」图标可获取实时信息（手动开启）
  5. 支持上传文件：图片 / PDF / Word / Excel / PPT，可解析长文档
  6. V4 支持 1M 超长上下文，可直接「读」整本书
打开网页版 ↗
02

手机 App

iOS / Android · 免费

  1. App Store 或各大安卓应用商店搜索「DeepSeek」
  2. 下载安装后登录（与网页版账号通用）
  3. 支持语音输入，说话即问即答
  4. 支持联网搜索、文件上传、长上下文对话
  5. 对话记录云端同步，网页与 App 无缝衔接
  6. 无订阅费、无次数限制 —— 真正免费
前往官网下载 ↗
03

API 接入（开发者）

platform.deepseek.com · 兼容 OpenAI SDK · 按量计费

  1. 前往 platform.deepseek.com 注册并登录
  2. 在「API Keys」页面创建密钥 sk-...，妥善保存
  3. 账户充值（支持支付宝，新用户有赠送额度）
  4. 接口地址：https://api.deepseek.com（与 OpenAI 格式兼容）
  5. 模型名：deepseek-v4-flash（轻量） / deepseek-v4-pro（旗舰）
  6. 历史模型名 deepseek-chat / deepseek-reasoner 已于 2026-07-24 退役
PythoncURL
# pip install openai
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的密钥",
    base_url="https://api.deepseek.com",
)
resp = client.chat.completions.create(
    model="deepseek-v4-flash",   # 或 deepseek-v4-pro
    messages=[
        {"role": "user",
         "content": "你好，介绍一下你自己"}
    ],
    stream=True,
)
for chunk in resp:
    print(chunk.choices[0].delta.content, end="")
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的密钥" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role":"user","content":"你好"}],
    "stream": true
  }'

FAQ

常见 问题

DeepSeek 收费吗？

网页版与手机 App 完全免费（无次数限制）；API 按 token 计费，价格远低于头部闭源模型，新用户有赠送额度。

需要「科学上网」吗？

不需要。DeepSeek 是国产模型，官方网页/App/API 在国内可直接访问。

API 与 OpenAI 兼容吗？

兼容。使用 OpenAI SDK 只需把 base_url 改为 https://api.deepseek.com 即可，模型名换成 deepseek-v4-flash / deepseek-v4-pro。

V4-Pro 正式版什么时候发布？

官方更新日志明确「The official release of DeepSeek-V4-Pro will follow soon」——即将推出，预计 2026 年内。

Flash 和 Pro 怎么选？

日常对话、简单 Agent、批量任务用 V4-Flash（快、便宜，AA 50 分）；复杂推理、长文写作、硬核代码用 V4-Pro（更稳更强）。

支持联网搜索吗？

网页版/App 需手动点击「联网搜索」图标开启；API 侧按官方文档传参。

上传文件支持哪些格式？

图片、PDF、Word、Excel、PPT、TXT 等均可上传解析；V4 的 1M 上下文可一次性处理超长文档。

我的数据安全吗？

官方提供隐私政策与数据使用说明；敏感数据建议走 API 并开启数据隔离选项（详见官方文档）。
